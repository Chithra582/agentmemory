# MCP Auto-Hook Intercept

## Overview
Seamlessly integrates with MCP-compliant coding agents (Claude Code, Cursor, Codex, Antigravity) to inject relevant project context pre-prompt and extract learnings post-turn.

## Key Capabilities
- Pre-prompt memory injection respecting token context budgets.
- Post-tool execution capture recording build failures and solutions.
- Zero-overhead non-blocking background synchronization.
